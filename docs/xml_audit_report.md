**Finding** — no structural markup (`note`, `quote`, `cit`, `q`, `bibl`) is used anywhere in the corpus to distinguish footnotes, editorial commentary, or quotations from other authors. Quoted material (e.g. Bergson quoting Yves Delage in the *Le rire* appendix) is embedded as plain running text delimited only by typographic quotation marks (`"…"`), which are indistinguishable at the XML level from ordinary emphasis or reported speech. **Decision needed before chunking**: since there is no tag to filter on, third-party quotations cannot be programmatically excluded or flagged; any chunk containing a long quoted passage will silently mix Bergson's voice with the quoted author's. Recommend a manual pass on works where this is most likely (argumentative chapters citing other philosophers), or a heuristic quotation-span detector as a Sprint 1 pre-processing step.

**Anomaly** — `sourceDesc` text does not mention any word from the work's own title for: 1888_EDIC. Manual check of `data/raw/corpus/raw/src/1888_EDIC.xml` shows its `sourceDesc` describes *L'Énergie spirituelle* while the file is *Essai sur les données immédiates de la conscience* — likely a copy-paste error in the source repo's `teiHeader` (only the URL is correct). Should be reported/fixed upstream before citing this field.

`publicationStmt/date` records the year of the **source edition** used for the encoding (a later reprint), not the first publication date — the two differ for several works (e.g. *Le rire*, first published 1900, encoded from the 1932/1924 edition). `metadata.csv/date` correctly holds the first publication date. Both values should be surfaced in citations to avoid conflating them.

Page-break (`pb/@n`) coverage is near-total for most works (numbered `pb` should roughly track the `pages` count from `metadata.csv`), meaning precise page-level academic citation is achievable from `raw/src` alone; unnumbered `pb` elements (front matter, plates) are expected and not an error.
